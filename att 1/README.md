# Student Attendance Calculator

## Project Overview
This project is a modern, responsive Student Attendance Calculator built with Flask, SQLAlchemy, SQLite, Bootstrap, and Chart.js. It helps students manage subjects, log attendance, monitor progress, and export reports.

## Features
- Student registration and login with secure password hashing
- Dashboard with attendance summary cards and charts
- Subject management with add, edit, and delete actions
- Attendance recording with Present/Absent actions
- Smart status badges for attendance safety
- Bunk and predictor insights
- Reports with search, sort, filter, and export to PDF/Excel
- Settings for profile updates, password changes, attendance thresholds, and dark mode

## Installation
1. Clone or open the project folder.
2. Install dependencies:
   pip install -r requirements.txt

## How to Run
1. Start the Flask app:
   python app.py
2. Open the browser at:
   http://127.0.0.1:5000
