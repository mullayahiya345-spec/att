# 📚 Attendance Calculator

A simple, fast, and responsive Attendance Calculator website that helps students track their subject-wise attendance and instantly calculate the attendance percentage required to meet minimum attendance criteria.

## 🚀 Live Demo

🔗 **Live Website:** https://your-live-link.com

## ✨ Features

- 📖 Subject-wise attendance management
- ✅ Mark classes as Present or Absent
- 📊 Automatic attendance percentage calculation
- 🎯 Shows attendance required to reach the target percentage
- 💾 Stores attendance data locally
- 📱 Responsive design for mobile and desktop
- ⚡ Fast and user-friendly interface

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Local Storage

## 🎯 Purpose

This project was built to help college students easily manage their attendance without maintaining manual records. It provides a clean interface to monitor attendance for each subject and helps students stay above the required attendance percentage.
